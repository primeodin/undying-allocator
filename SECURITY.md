# Security Policy

This is a retrospective educational archive, not production infrastructure.

## Supported use

- Run examples locally or in disposable containers.
- Treat deployment scripts as dry-run teaching material unless explicitly marked otherwise.
- Do not place secrets in examples, fixtures, commit messages, or issue text.

## Reporting

Open a private security advisory on GitHub if available, or contact the repository owner through GitHub. Include:

- affected file/path,
- exact command used,
- observed behavior,
- why it matters.

The Rune-King rule is simple: if a rune can cut the next traveler, blunt it before it leaves the forge.
