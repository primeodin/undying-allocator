# Contributing

This archive values clear, runnable, inspectable changes over heroic bulk.

Before sending a patch:

1. Run `./scripts/smoke.sh`.
2. Keep the retrospective framing honest.
3. Prefer one readable implementation over many generated variants.
4. Add tests for new behavior.
5. Avoid secrets, network side effects, and real deployment unless the README says so.

Good contributions leave the next reader with a sharper tool and fewer mysteries.
