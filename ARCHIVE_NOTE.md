# Archive Honesty Note

This repository is part of `primeodin-legacy`, an openly retrospective technical autobiography.
It is not presented as a repository that existed in the year named by its chapter. The code,
commit messages, tags, and prose are current reconstructions written to study a historical
engineering style and to preserve a mythic personal voice without falsifying public record.

The rule is simple: make the legend strong enough that it does not need to lie.
